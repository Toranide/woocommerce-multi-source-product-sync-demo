# راهنمای فارسی — همگام‌ساز چندمنبعی محصولات ووکامرس

**نسخه:** 1.4.4  
**ناشر:** Toranide  
**مجوز:** GPL-2.0-or-later

## معرفی

این افزونه محصولات را از چند فروشگاه دارای WooCommerce REST API دریافت و در فروشگاه مقصد ایجاد یا همگام‌سازی می‌کند. تنظیمات، نگاشت فیلدها و برنامهٔ اجرای هر منبع مستقل است.

## پیش‌نیازها

- WordPress نسخهٔ ۶.۲ یا جدیدتر
- WooCommerce نسخهٔ ۷.۰ یا جدیدتر
- PHP نسخهٔ ۷.۴ یا جدیدتر و پشتیبانی OpenSSL
- کلید REST API مبدأ با سطح دسترسی فقط‌خواندنی

## نصب

۱. از صفحهٔ مخزن، گزینهٔ **Code → Download ZIP** را انتخاب کنید.  
۲. در پیشخوان وردپرس وارد «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» شوید و ZIP را بارگذاری کنید.  
۳. ابتدا WooCommerce و سپس این افزونه را فعال کنید.  
۴. از منوی «همگام‌ساز محصولات» یک منبع اضافه کنید.  
۵. آدرس سایت مبدأ، مسیر API و کلیدهای REST API را وارد کنید.  
۶. اتصال را آزمایش کنید و ابتدا همگام‌سازی آزمایشی کوچکی انجام دهید.

## نگاشت فیلدها

- فیلدهای استاندارد محصول را از فهرست مقصد انتخاب کنید.
- برای متای سفارشی از قالب `meta:your_key` استفاده کنید.
- برای تاکسونومی سفارشی از قالب `taxonomy:your_taxonomy` استفاده کنید.
- هر ردیف نگاشت می‌تواند مقدار را از مبدأ بگیرد، مقدار ثابت ثبت کند یا در نبود مقدار مبدأ از مقدار پیش‌فرض استفاده کند.
- برای برند، کلید واقعی متا یا نام تاکسونومی افزونهٔ برند نصب‌شده روی مقصد را وارد کنید؛ این مقدار بین افزونه‌ها یکسان نیست.

## زمان‌بندی و قیمت

برای هر منبع، فاصلهٔ اجرای زمان‌بندی و ساعت مبنا را مستقل تعیین کنید. ضریب قیمت نیز برای هر منبع قابل تنظیم است. دکمهٔ اجرای دستی برای شروع فوری وجود دارد. اجرای زمان‌بندی‌شده به Cron وردپرس و Action Scheduler وابسته است؛ برای سایت‌های کم‌ترافیک، Cron واقعی سرور می‌تواند مفید باشد.

## ایمنی و محدودیت‌ها

- قبل از همگام‌سازی انبوه از سایت مقصد پشتیبان بگیرید و ابتدا روی محیط آزمایشی کار کنید.
- فقط API سازگار با WooCommerce پشتیبانی می‌شود؛ APIهای سفارشی با ساختار متفاوت پشتیبانی عمومی ندارند.
- رفتار متا، برند و تاکسونومی به ساختار واقعی افزونه‌های مقصد وابسته است.
- این نسخه هنوز روی همهٔ ترکیب‌های نسخه و همهٔ فروشگاه‌ها جامع آزمایش نشده و ممیزی امنیتی مستقل ندارد.
- هیچ کلید API، رمز عبور، توکن یا اطلاعات شخصی را در گزارش عمومی منتشر نکنید.
