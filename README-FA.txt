راهنمای انتشار صفحه معرفی در GitHub Pages

این بسته شامل index.html است و به سرور PHP یا دیتابیس نیاز ندارد.

۱) وارد حساب GitHub شوید و یک Repository جدید با نام woocommerce-multi-source-product-sync-demo بسازید.
۲) Repository را Public قرار دهید.
۳) فایل index.html را در ریشهٔ Repository بارگذاری کنید و Commit changes را بزنید.
۴) از Settings > Pages، بخش Build and deployment را روی Deploy from a branch قرار دهید.
۵) Branch را main و پوشه را /(root) انتخاب کنید و Save را بزنید.
۶) پس از ساخته‌شدن سایت، GitHub نشانی Pages را در همان بخش نشان می‌دهد. آدرس معمولاً به شکل زیر خواهد بود:
   https://YOUR-USERNAME.github.io/woocommerce-multi-source-product-sync-demo/
۷) همان آدرس را در فیلد «لینک دمو» راست‌چین وارد کنید؛ فقط اگر راست‌چین صفحه معرفی را به عنوان دمو می‌پذیرد.

نکات:
- این صفحه دمو معرفی است، نه پنل عملیاتی یا محیطی که همگام‌سازی واقعی انجام دهد.
- متن صفحه عمداً از وعده قطعی عملکردهای آزمایش‌نشده پرهیز می‌کند.
- هرگز API Key، Consumer Secret، رمز عبور یا فایل لایسنس را در این Repository عمومی قرار ندهید.
- اگر راست‌چین دمو عملی بخواهد، باید یک سایت آزمایشی WordPress + WooCommerce جداگانه با داده ساختگی راه‌اندازی شود.
