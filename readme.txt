واردکردن و همگام‌سازی محصولات از چند فروشگاه دارای WooCommerce REST API، همراه با نگاشت فیلدها، مقادیر ثابت و پیش‌فرض و زمان‌بندی مستقل.

== Description ==

این افزونه برای مدیریت چند منبع WooCommerce REST API طراحی شده است. هر منبع می‌تواند نگاشت فیلد، مقدار ثابت و پیش‌فرض، ضریب قیمت و زمان‌بندی مستقل داشته باشد. اجرای دستی، آزمایش اتصال API و ثبت گزارش عملیات نیز فراهم است.

این نسخه رایگان و جامعه‌محور است و شامل لایسنس تجاری راست‌چین یا خروجی ionCube نیست. فقط API سازگار با WooCommerce پشتیبانی می‌شود.

== Installation ==

1. فایل ZIP این مخزن را دریافت کنید.
2. از پیشخوان وردپرس، افزونه را بارگذاری و فعال کنید.
3. WooCommerce را فعال نگه دارید.
4. یک منبع با REST API و کلید دارای سطح دسترسی فقط‌خواندنی اضافه کنید.
5. اتصال و همگام‌سازی محدود را در محیط آزمایشی بررسی کنید.

== Frequently Asked Questions ==

= آیا API هر سایتی پشتیبانی می‌شود؟ =
خیر؛ API باید با WooCommerce REST API سازگار باشد.

= آیا قبل از استفاده باید پشتیبان گرفت؟ =
بله. ابتدا محیط آزمایشی و نسخهٔ پشتیبان توصیه می‌شود.
