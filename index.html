فقط اطلاعاتی را منتقل کن که نیاز داری

فیلدهای متداول محصول را می‌توان به فیلد مقصد نگاشت داد. برای داده‌هایی که در سایت مبدأ وجود ندارند نیز می‌توان، در صورت پشتیبانی فیلد مقصد، مقدار ثابتی در نظر گرفت.

قبل از شروع بدان

آیا از هر API دلخواهی می‌توان استفاده کرد؟

این افزونه برای API سازگار با ساختار محصولات WooCommerce REST API طراحی شده است. APIهای با ساختار متفاوت ممکن است به سازگارکننده اختصاصی نیاز داشته باشند.

آیا محصولات جدید هم وارد می‌شوند؟

هدف افزونه بررسی محصولات قابل‌دریافت و ایجاد محصولات جدید یا به‌روزرسانی محصولات شناسایی‌شده است. نتیجه به دسترسی API، نگاشت و تنظیمات منبع وابسته است؛ پیش از استفاده عملی، این رفتار را در یک فروشگاه آزمایشی بررسی کن.

آیا شناسه محصول در مبدأ و مقصد باید یکی باشد؟

خیر. شناسه محصول در مقصد می‌تواند متفاوت باشد. شناسایی محصولات قبلی به اطلاعات قابل تطبیق و ثبت ارتباط منبع بستگی دارد.

آیا این صفحه یک دمو زنده است؟

این صفحه، پیش‌نمایش معرفی و امکانات محصول است؛ فرم‌ها و داده‌های تصویری آن به فروشگاه واقعی متصل نیستند. برای آزمایش عملی، افزونه باید در محیط وردپرس و ووکامرس نصب و پیکربندی شود.
