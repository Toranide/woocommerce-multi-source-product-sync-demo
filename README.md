# همگام‌ساز چندمنبعی محصولات ووکامرس | WooCommerce Multi-Source Product Sync

![تصویر داشبورد همگام‌ساز چندمنبعی محصولات ووکامرس](WooCommerce%20Multi-Source%20Sync%20Dashboard.png)

**نسخه:** 1.4.4 · **ناشر:** Toranide · **مجوز:** GPL-2.0-or-later

افزونه‌ای رایگان برای واردکردن و همگام‌سازی محصولات از چند فروشگاه مبدأ که **WooCommerce REST API** را ارائه می‌کنند. برای هر منبع می‌توان نگاشت فیلدهای مستقل، مقادیر ثابت و پیش‌فرض، ضریب قیمت، اجرای دستی و زمان‌بندی جداگانه تنظیم کرد.

> صفحه معرفی پروژه: https://toranide.github.io/woocommerce-multi-source-product-sync-demo/  
> این صفحه معرفی است و یک دموی زنده وردپرس نیست.  
> **دریافت نسخه نصب و Releaseها:** [صفحه انتشارها](https://github.com/Toranide/woocommerce-multi-source-product-sync-demo/releases).

## امکانات

- اتصال به چند فروشگاه مبدأ مبتنی بر WooCommerce REST API
- نگاشت فیلدهای محصول به مقصد، همراه با مقدار ثابت یا مقدار پیش‌فرض
- پشتیبانی از کلیدهای متا با قالب `meta:your_key` و تاکسونومی با قالب `taxonomy:your_taxonomy`
- ضریب قیمت و تنظیم زمان‌بندی مجزا برای هر منبع
- اجرای دستی و آزمایش اتصال API
- ایجاد محصول و تطبیق محصولات واردشدهٔ قبلی
- ثبت گزارش عملیات و خطاهای همگام‌سازی
- رابط مدیریتی فارسی و راست‌چین

## پیش‌نیازها

- WordPress 6.2 یا جدیدتر
- WooCommerce 7.0 یا جدیدتر
- PHP 7.4 یا جدیدتر و فعال بودن OpenSSL
- کلید REST API مبدأ با دسترسی فقط‌خواندنی

## نصب

1. این مخزن را از طریق **Code → Download ZIP** دریافت کنید.
2. در وردپرس به **افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه** بروید و ZIP را انتخاب کنید.
3. WooCommerce را فعال کنید و سپس افزونه را فعال کنید.
4. از منوی «همگام‌ساز محصولات» یک منبع اضافه کنید.
5. آدرس سایت، مسیر API و کلیدهای REST API را وارد و اتصال را آزمایش کنید.
6. ابتدا روی یک سایت آزمایشی و تعداد کمی محصول همگام‌سازی را امتحان کنید.

## نکات مهم

- این نسخه رایگان و جامعه‌محور است؛ فایل لایسنس تجاری راست‌چین و خروجی رمزگذاری‌شدهٔ ionCube در آن وجود ندارد.
- فقط API سازگار با WooCommerce پشتیبانی می‌شود؛ APIهای اختصاصی نیازمند توسعهٔ جداگانه‌اند.
- پیش از واردکردن حجم زیاد محصولات، از فروشگاه مقصد نسخهٔ پشتیبان بگیرید.
- کلیدهای سفارشی برند، متا و تاکسونومی به افزونه‌ها و تنظیمات فروشگاه مقصد وابسته‌اند.
- این نسخه روی همهٔ ترکیب‌های وردپرس، ووکامرس، PHP و فروشگاه‌ها به‌طور جامع آزمایش یا ممیزی نشده است.
- زمان‌بندی به Cron وردپرس و Action Scheduler وابسته است. برای سایت‌های کم‌ترافیک، Cron واقعی سرور را در نظر بگیرید.
- هرگز API Key، رمز عبور یا اطلاعات شخصی را در Issues یا گزارش‌های عمومی قرار ندهید.
